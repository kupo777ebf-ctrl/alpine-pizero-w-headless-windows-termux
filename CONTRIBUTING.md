# Contribuer

Merci de contribuer à rendre ce guide plus clair et plus fiable.

## Avant une pull request

- Vérifie les commandes sur la version d'Alpine indiquée.
- Indique le modèle exact de Raspberry Pi utilisé.
- Ne présente pas une étape comme testée si elle n'a pas été exécutée sur le matériel.
- Ne soumets aucun mot de passe, fichier de configuration Wi-Fi réel, clé privée ou identifiant.
- Préfère des étapes courtes, avec le résultat attendu et une méthode de dépannage.

## Format

- Langue principale : français.
- Utilise des titres Markdown hiérarchisés.
- Explique les commandes non évidentes.
- Garde les fichiers d'exemple exempts de secrets.
